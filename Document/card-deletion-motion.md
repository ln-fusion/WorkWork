# 删牌刀光与两半消散（2026-10-17）

用户要求并已实现：一道刀光横扫，牌面分成上下两半，错开、旋转并淡出。使用原生UI绘制刀光，使用原卡牌预制体的两个裁剪副本显示两半，不需要额外美术资源，也不修改原图或预制体。

## 触发与顺序

- 行政、公关：正常牌面计分后，到员工实际删牌步骤斩断本工位牌。
- 三人合影：同一步批量斩断实际存在的目标，错峰并行；不重算牌面或附魔。
- 小夜灯：逐张完成该牌额外牌面、附魔，包括复制上送与重抽反馈，然后由小夜灯来源发出独立删牌步骤，再斩断。不能在额外计分之前就把牌隐藏。
- 法务：抽牌堆、弃牌堆的目标没有在场图像，在员工附近短暂显示目标牌，然后刀光斩断，不提供牌库查看界面。
- 只有真实成功删除才生成事件，空目标与条件不符不播放；重复小夜灯不能对同一实体反复删牌。
- 原场上牌当场隐藏，并排除出整轮末尾的收牌动画，不再错误地回收到上方。动画取消或返回欢迎恢复尚未提交的真实状态。

## 参数

场景 **WorkWork MVP → Card Deletion Feedback**：

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| Slash Duration | 0.1秒 | 刀光扫过时间 |
| Split Duration | 0.4秒 | 两半分离、旋转和消失时间 |
| Separation | 40 | 上下分离距离 |
| Sideways | 22 | 左右错开距离 |
| Rotation | 12度 | 两半朝相反方向旋转幅度 |
| Card Stagger | 0.04秒 | 同批牌的错峰间隔 |
| Slash Color | 暖白外光 | 刀光外层颜色，中心为白色 |

总时长默认约0.5秒，同批多牌并行。WorkWork/Configure Card Deletion Feedback为装配入口，不重置已有参数；完整生成链包含装配，但日常调参数不运行完整UI生成。

## 接口和清理

- ScoreStep.deletedCards携带实际删除牌的独立快照，与生成、复制、改牌事件分开。结算预览仅计算快照，不删除真实会话中的牌。
- CardDeletionFeedback.Play(game,cards,source)播放裁剪副本；可见目标使用CardView当前展示的点数、花色和附魔，避免斩断时倒回未加工牌面。
- 上下半各用RectMask2D裁剪完整牌，刀光用不可交互UI图形绘制；CanvasGroup禁止射线。临时层名为Card Deletion Layer，结束清理，原牌由隐藏集合保持隐藏。
- IsDeleted供GameController过滤末尾收牌；Clear/CancelScoring/停用销毁临时层、恢复原始透明度并清空删除标记，不发任何新奖励。
- 开始前等原有牌面跳动结束，避免截取移动中的姿态造成抖动。实际删除仍由GameSession一次性提交原结算结果，动画不调用DeleteCard。
