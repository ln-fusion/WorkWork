# 进入商店时的目标与分数（2026-10-15）

胜利结算仍使用刚结束月份的目标、累计分数及收入。在 OpenShop 成功进入商店时，将 target 设置为下个月目标，monthScore 清零，并清除上周 lastScore；不再结算或改动现金、收入及月结算摘要。月份和牌库仍在点击下一月时推进/重置。

下个月目标和正式开月共用 TargetForMonth，保留原来的逐月增长与向上取整规则，避免在商店、正式开月各增长一次。旧的商店存档读取时同样归一化为下月目标、零累计分。

验证：直接编译并运行 Core C#，通过胜利结算→商店→下月流程、收入不变、重复进入商店拒绝，以及第 1/12/24/36 月的存档恢复与开月目标一致检查。RulesTests 已增加对应测试；本轮未执行完整 Unity Test Runner。
