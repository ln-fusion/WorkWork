# 花色与点数变化动画（2026-10-17）

用户确认：数字和花色采用相同的缩小淡出、放大出现，放大超过最终大小一点，再回弹。已实现，不采用数字滚动或随机数。

- 改动的花色图标、数字先缩小淡出，换成新内容后放大到115%，再回到原大小。花色变化导致红黑颜色改变时，数字同步用相同过渡切换颜色；同色改花色且点数不变时只处理花色图标。
- 同一卡同时改点和改花色，两处并行，卡牌只轻弹一次。不改变点数或花色的赋值不产生动画。
- 播放顺序：牌面变化 → 对应附魔消失/出现 → 后续步骤。员工和道具均支持；土豆、冲锋枪依次改同一张牌时，分别展示各次前后值，不只展示最终值。
- 原有牌面结算仍先执行，改点改色不重判当周牌型、不追溯已执行得分。CardView的牌面覆盖只用于显示，规则仍由结算快照提交。

## 调整入口

WorkWorkMvp场景的 **WorkWork MVP → Card Face Feedback**：

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| Disappear Duration | 0.12秒 | 旧内容缩小淡出 |
| Appear Duration | 0.16秒 | 新内容放大、淡入到最大尺寸 |
| Settle Duration | 0.1秒 | 从最大尺寸回弹至原尺寸 |
| Overshoot Scale | 1.15 | 最大尺寸相对原尺寸的倍率 |
| Jump Height | 6 | 卡牌轻弹高度 |

总时长默认0.38秒。只增加组件及引用，没有调整卡牌预制体尺寸、文字字体、槽位锚点或布局。WorkWork/Configure Card Face Feedback用于装配缺失组件，已有参数不重置；完整UI生成链也包含此装配。

## 接口与清理

- ScoreStep.faceChanges记录cardId、beforeRank、afterRank、beforeSuit、afterSuit；只对原有手牌及场上牌的真实牌面变化生成。
- CardFaceFeedback.Play(game,changes)等待本步骤牌面播放结束；GameController随后播放enchantmentChanges，再进入后续结算。
- CardView.PresentFace/ResetPresentedFace只切换显示，不改BoundCard。LateUpdate不会把正在展示的快照牌面立即刷回旧值。
- Clear/CancelScoring/停用时还原位置、缩放、透明度与真实牌面；正常完成保持新牌面，直到渲染提交的实际状态。
- 结算节奏很快时，先等原有卡牌跳动结束，避免两个动画同时修改同一个RectTransform导致位置漂移。
