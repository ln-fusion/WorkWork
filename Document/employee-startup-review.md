# 员工启动性与附魔密度调整建议（2026-10-16）

后续进展：已完成 [employee-effects-v2.md](employee-effects-v2.md) 的33名完整重写，用户修改后已接入。本文作为问题分析和前期建议保留，具体第二版效果、价格与边界以新稿为准；实现与验证见 employee-revision-integration.md。

用户实际游玩反馈：附魔太少；许多利用附魔、牌数或同点数的员工缺少自身生产手段。本文为下一轮调整建议，尚未覆盖正式员工表、运行代码或目录配置。

## 最新确认：依赖特殊启动条件的员工必须自带启动因子

用户明确要求这是一条统一原则，不只是每个流派挑一个入口员工。凡依赖某种附魔、增牌、复制、减牌等特殊条件的员工，自身必须具有提供该因子的能力。搭配用于增强覆盖、效率、收益，不应成为该员工从无效变为有效的唯一前提。此前建议“少数高收益放大员工可以没有启动手段”撤回。

- 吃“金币”就能赋予“金币”；吃某种其他附魔也要能自己提供。
- 吃附魔种类数就能逐步赋予不同附魔；不能只有计数奖励。
- 吃同点数牌数或牌库扩充就能复制、生成匹配牌，或精准赋予“复制”。
- 吃删牌事件、空位或精简后的牌库就能按条件删牌；不能只等其他员工制造空位。
- “金币”“粉丝”“同花加分”“点数翻倍”“双倍”可按整个点数或整个花色覆盖，例如所有6、所有方片，不默认添加花色与点数的双重限制。
- 只有“复制”“重抽”附魔继续要求同时限定花色与点数。直接复制技能也必须明确次数和触发时机，不能以换名字的方式形成无限复制。
- 自带启动因子是能主动推进条件，不是无条件保证获得全部奖励；新增牌仍需抽取，附魔满槽仍不能添加，删牌仍须有合法目标。

## 当前问题

目前8名持有附魔员工全部限定花色与点数，基础48张牌中各自只覆盖2张。原要求只限制“复制”“重抽”两种附魔，其他附魔也全用同一精度，导致覆盖过窄。音乐音效、数值策划等放大能力比可用附魔来源多；活动策划、供应链等缺少自身提供材料的能力。

每月仅4周且牌堆重置，不能把多次抽回改造牌视为稳定收益。往牌库塞牌不会立即增加场上牌数，也不会重判本次牌型。

## 建议方案，数值待确认

| 员工 | 建议调整 | 可以连接的方向 |
| --- | --- | --- |
| 客服 | 将“红桃6获得金币”放宽为所有红桃获得“金币”，保留红桃数量奖励。 | 红桃、附魔、基础分 |
| 文案策划 | 将“红桃3获得粉丝”放宽为所有3点牌获得“粉丝”，保留本工位奇数红桃奖励。 | 点数3、红桃、奇数、附魔 |
| 界面与体验 | 将“方片2获得点数翻倍”放宽为所有2点牌获得“点数翻倍”，保留2或4点奖励。 | 低点数、偶数、附魔 |
| 社群运营 | 将“黑桃6获得同花加分”放宽为所有黑桃获得“同花加分”，保留附魔牌数量奖励。 | 黑桃、同花、附魔 |
| 音乐音效 | 结算时先尝试给本工位牌添加“同花加分”，再额外结算一次该附魔；保留邻牌同色奖励。已拥有时不重复添加，但仍额外结算；满槽且无该附魔时不能添加或额外结算。 | 自身启动、同花、附魔重复计分 |
| 数值策划 | 结算时，若本工位牌有空附魔槽，从未拥有的“金币”“粉丝”“同花加分”“点数翻倍”“双倍”中随机添加一种，再按附魔种类获得现有奖励。 | 自身启动、附魔成长、补齐“双倍”来源 |
| 活动策划 | 每次结算将本工位牌复制1张入牌库，保留同点数奖励。直接复制技能不赋予“复制”附魔，副本仍不继承“复制”；每次员工结算最多一次。 | 同点数、复制、扩充、生成收益 |
| 供应链管理 | 每次结算加入1张与本工位同花色的1点牌，无牌时花色随机；随后读取牌堆规模，再处理三件同名道具倍乘。 | 1点、花色、扩充、装备 |
| 财务 | 将“方片6获得金币”放宽为所有方片获得“金币”，保留资金存量奖励。 | 方片、附魔、资金 |
| 市场营销 | 将“红桃2获得粉丝”放宽为所有2点牌获得“粉丝”，继续按带该附魔的牌数奖励。 | 点数2、附魔 |
| 市场经理 | 自带一类常见牌的“金币”赋予，另能生成牌，分别支撑“金币”触发和新增牌奖励；可测试所有6获得“金币”，结算生成一张6点牌。 | 点数6、金币、生成 |
| 行政管理 | 按条件删除本工位低点牌，再读取空位和精简后的规模；让自己的删牌也能支撑自身收益。 | 低点数、删牌、空位、精简 |
| 校对 | 自带0点牌生成，再将抽到的0点牌改成1点，保留1点收益；不必先找到闹钟或运营。 | 0点、1点、生成、改造 |
| 动画 | 自身能给本工位牌添加“点数翻倍”，再执行既有额外计分；仍不额外触发“复制”“重抽”。 | 普通附魔、牌面、额外计分 |
| 技术美术 | 自身也能改花色，再按改色条件添加“粉丝”；不能必须先让美术或建模加工后才能工作。 | 改色、附魔 |

其余岗位也应按“条件—自身提供手段—收益”逐项检查；已有启动手段的美术设计、特效师、游戏测试、程序、游戏运营、法务、公关等不为凑数量额外堆无关能力。确切生成数量、附魔范围和价格以整表重排后的版本讨论，不将此比较表直接导入游戏。

“复制”“重抽”的赋予仍必须限定花色与点数，不扩大范围。同种附魔不可重复、每牌最多4种、副本不继承“复制”、售出按来源移除、月初重建和整数倍率均保留。

普通附魔覆盖范围以现有基础牌组为例：一个完整花色为12张，一个完整点数为8张。允许大范围赋予，后续通过收益、价格和组合表现测试平衡，不以重新压窄到两张牌作为默认平衡手段。

## 结算和取舍

- 新增附魔仍在员工执行时产生，不倒回补算本次已经完成的牌面与附魔。音乐音效明确额外结算，因而可以当次兑现新加的“同花加分”；数值策划当次兑现的是附魔种类奖励，新附魔的常规计分需等以后。
- 员工主动添加的附魔记录来源，售出移除该来源。随机赋予只选择缺少的种类，满4种直接跳过，不能把失败赋予记成永久原生来源。
- 活动策划复制的牌只加入抽牌堆，不能把副本直接算成场上第二张同点牌；即时收益仍依赖当前摆牌，后续抽取逐步提高目标牌占比。
- 每名依赖特殊启动条件的员工都须自带对应生产能力；其他岗位和道具提供额外来源、提高效率或放大收益，而非独占启动钥匙。自带生产能力不等于必须同时具备倍乘。
- 若试玩仍觉得生成牌难以见效，应另评估检索、额外抽取或改变手牌的能力。不能仅提高塞牌数量，否则可能让关键牌更难抽到；本轮不自动增加这些操作。
- 正式改表时，需要在每条效果最下方保留涉及附魔的中文释义；本提案表仅用于比较改动，不作为完整玩家展示文本。
