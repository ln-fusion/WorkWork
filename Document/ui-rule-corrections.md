# UI 与规则更正（2026-10-14）

以用户最新指示为准：基础倍率为 1，再加最强牌型和员工/道具效果。主界面目标下方显示本月累计分数，不是现金。

每名员工有 3 个道具槽，总计 18 槽。商品仅能拖动购买：拖入员工区域时道具放入首个空槽；拖入指定道具槽时按该槽购买。点击商品不购买。三件道具均参与效果结算。交换员工携带全部道具；独立道具移动与出售仍限商店，出售不会让后面的道具补位。旧 6 槽存档映射到各员工的第一槽。

商店六个固定商品栏：前 3 员工、后 3 道具；购买后原栏留空，不自动向前补位；点击刷新时重新生成商品并补上空栏。员工持有期间不会重复上架，成功售出后回到商品池，可在后续刷新再次上架；道具当前仍保留已购后不重复上架的规则，候选库存耗尽时无法补满。每栏分别配置商品图片、黑板数字价格、底栏名字；商品栏不显示技能与描述，右键浮窗分别显示名字与效果（已实现）。刷新按钮只显示数字价格；红色箭头进入下个月；绿色区域只显示现金数字。

修改现有场景的菜单：WorkWork/Apply UI Corrections；完整美术场景生成器也包含这些更正。字体仍统一使用 Assets/Fonts/LXGWMarkerGothic-Regular SDF.asset；页面背景仍为独立 Image。

验证：33 项 EditMode 规则测试全部通过（包含购买后留空、刷新补货验证）；运行时放牌/收牌、月结算/商店/下月、素材替换、独立背景、自适应与音量验证通过。新增 UI 绑定检查通过：分数/现金分离、18 槽、商品名字与数字价格、购买栏位留空。预览使用临时运行状态，没有保存或覆盖玩家存档。


员工售出回池修正：成功出售后解除该员工的池子排除标记；附带道具导致出售失败时保持排除。验证包含出售返款、刷新重新上架、再次购买、存档往返。
